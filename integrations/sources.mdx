Data sources are how Tranthor learns about your customers, so you can personalize campaigns, measure outcomes, and move faster with confidence.

## Available data sources

- [Tranthor Application Programming Interface (API)](https://docs.tranthor.com/integrations/sources/api): Go live quickly with direct event and profile syncing.
- [Segment](https://docs.tranthor.com/integrations/sources/segment): Plug Tranthor into your existing data pipeline for faster activation.
- [Shopify](https://docs.tranthor.com/integrations/sources/shopify): Bring commerce signals into lifecycle campaigns automatically.
- [WooCommerce](/integrations/sources/woocommerce): Connect a WooCommerce store. This source is live.
